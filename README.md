# NŠK Zlatna Luka - Website

This is the official website of the sports club **NŠK Zlatna Luka**, created as an HTML/CSS project. The site provides information about the club, team, stadium, news, and allows ticket purchases.

## Project Structure

The project is organized as follows:
- **index.html** - The homepage of the website.
- **Other HTML pages** - Contain additional information about the club, rules, contacts, and ticket purchasing.
- **css/** - Contains website styles.
- **images/** - All images used on the site, including logos, icons, and player pictures.
- **club/** - Pages related to the team, coaching staff, and stadium.
- **news/** - Club-related news and articles.

## How to Run the Project

1. Download or clone the repository.
2. Open `index.html` in a web browser.

## Technologies Used
- **HTML** - Page structure.
- **CSS** - Styling and design.
- **JavaScript** - Interactive elements (ticket purchasing).
